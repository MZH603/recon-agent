# 覆盖记录与否定证据

## 目标

准确说明检查了什么、没有检查什么，以及工具结果的可靠性边界。

## 记录方法

- 使用 `recon_coverage` 记录测试面、目标、方法、结果和未测原因。
- 只有存在当前目标的本地证据 ID 时，才将结果标为 `verified`。
- 使用 `evidence_search`、`evidence_get` 或 `artifact_read` 复核已有本地记录；分页或截断结果不得当作完整数据。
- 区分已观察、推断、候选、验证和不确定；把超时、解析失败、门控拒绝和未启用工具分别记录。

## 否定结论

有限字典无结果、端口列表有限、路径未命中、超时或工具不可用，都不能证明目标不存在相应资产或风险。报告覆盖上限和未执行项目，不将“未发现”写成“无风险”。
