# 资产发现与授权范围

## 目标

为用户明确授权的域名或 IP 建立有边界的资产清单，并记录来源、解析状态与失败项。

## 工具选择

- DNS 记录查询使用 `dns_query`。
- 子域候选收集使用 `subdomain_enum`；需要第二个独立被动来源时，可使用已启用的 `subfinder_enum`。
- Web 可达性与快速技术栈识别分别使用 `httpx_probe`、`fingerprint`。
- 只有用户提出端口盘点需求且完成 L1 门控时，才使用 `nmap_scan`。

## 范围和证据

以用户指定的授权域名/IP 为根范围；证书、历史数据、DNS、链接和共用 IP 只能产生候选，不会自动扩展授权。记录字典/来源上限、不可解析资产、工具失败与降级。候选和部分枚举结果不能表述为完整资产全集。
