# 第一阶段：LangGraph 会话编排

用户已批准实施本方案直到完成。仅替换 `recon-agent V1.0/cli/session.py` 的会话行为，默认 CLI 流水线保持原模式。Skill、本地知识 RAG、工具组合和 MCP 协议升级属于后续阶段。

## 交互与架构

启动仍使用 `-t TARGET --authorized --session`。进入后等待任务，不能自动扫描或在模型故障时自动运行旧流水线。复用 LiteLLM 的 LLMService、ToolRegistry 和全部现有 L0/L1/L2 工具。LangGraph 显式节点负责模型决策、参数/范围/预算检查、授权中断、执行和结果评估；一次只执行一个工具动作，多工具响应按顺序处理。

模型能选择真实工具调用、提出澄清问题及完成任务。提供编排控制工具用于更新计划、询问用户、完成任务；原生调用和现有 XML 兼容。任务保存目标、消息、计划、待办调用、完整 ToolResult、证据/冲突/失败、执行记录、预算和状态。继续和改变关注点沿用会话结果；报告使用真实结果。

## 暂停与恢复

使用官方 AsyncSqliteSaver，数据库存于应用状态目录 `agent_state.sqlite`，独立于原缓存，不需外置服务。生成会话 ID；CLI 增加 `--resume SESSION_ID`（仍需 `-t` 且匹配）。澄清、工具失败后的选择、超过有限参数修正、预算限制、模型不可用、冲突及执行结果不确定通过 interrupt 保存并暂停；回答通过 Command(resume=...) 继续。可报告、退出或 abort；EOF 保存后退出。

授权仅在当前进程有效。L1 一次确认；L2 三次独立准确确认和每动作确认。参数/范围检查在询问前发生。非 TTY/batch 禁止 L2。重启重新校验并询问，checkpoint 内的旧授权不授予权限。门控中断不能重放扫描副作用。执行前写入持久 journal，完成后存完整结果；崩溃留下 started 的动作标记为 uncertain 并询问，禁止盲目重执行。完成 journal 可用于 checkpoint 落盘前崩溃的结果恢复。重复调用复用同任务已完成成功结果，保留完整结构和缓存标记，不作为错误。

## 边界与结果

参数错误最多两次自动修正后询问；工具失败不自动重复主动探测，询问用户是否调整任务。有限模型/工具步数耗尽时保存并询问，不能无限循环。预算累计跨恢复保留；预算耗尽可生成部分报告，不继续模型或主动扫描。模型不可达保留任务，不隐式网络扫描。报告记录 DNS、资产、IP、端口、指纹、路径、来源以及失败、降级、冲突和未完成状态；JSON 保留完整工具执行记录，Markdown 可追溯，遵守 output-format/output-dir。

## 验收

用脚本模型与本地假工具验证真实 LangGraph/SQLite：启动零模型零扫描；自然语言任务执行工具并报告；澄清暂停回答恢复；L1/L2 不能绕过；重启再次授权；恢复成功结果不重复执行；started 动作停下询问；越界/非法参数禁止执行；失败、模型不可用、预算耗尽和步数耗尽可退出/报告；多工具响应不突破执行上限；报告包含实际结构、错误和完整来源。运行旧项目离线测试回归及 CLI 帮助/交互烟测，不扫描外部目标。
