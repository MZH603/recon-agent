# 受控 CLI、浏览器 MCP 和代理流程

## 目标

在使用集成工具时，遵守显式启用、schema 检查、范围限制与级别门控。

## 调用顺序

- 先用 `tool_catalog` 查找已注册工具，并选择所需的延迟披露 schema；列出或选择工具不等于授权。
- 调用 MCP 前先用 `mcp_tools` 检查已允许工具及其 schema；仅对显式 allowlist 中且配置 `target_fields` 的工具调用 `mcp_call`。
- 已审阅的自定义工具仅使用配置定义的参数。命令/脚本至少 L2，HTTP 集成至少 L1；`shell` 提示不是可执行命令。
- 外部扫描器仅在 profile 明确启用并可用时调用；优先最小请求数、最少目标和固定参数。旧版或随附二进制不是注册工具。
- 代理查询只读取 Caido 中已捕获且属于当前授权范围的元数据；没有此需求时不要连接 Caido。

## 安全和证据

所有目标交互经 `ToolRegistry.execute()`；不得通过 shell、临时脚本或自行构造 HTTP 请求绕过校验。执行前按工具最低级别完成授权门控；对 L2 遵守逐项确认。报告失败、超时、跳过、范围过滤和截断，不将外部情报当作目标实测。
